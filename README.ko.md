# SonTool v3.0

**사람과 다양한 AI가 같은 창작 자산을 만들고 발전시키는 공통 기반입니다.**

[English](README.md) · [조사](docs/research.md) · [구현 결정](docs/decisions/0002-foundation-runtime.md) · [검증·남은 조건](docs/verification.md)

기존 SonETool과 별개의 공개 프로젝트입니다. 공통 작품 파일을 SonTool GPT, SonTool App과 여러 미디어 도구에서 활용하는 방향을 유지합니다. 작품의 정체성과 원본 데이터 보존을 목표로 하며, 웹·영상·앱에서 완전히 같은 경험을 보장하지는 않습니다.

현재는 **실험용 기초 구현**입니다. 안정 규격 출시나 운영 서비스 연동 완료가 아닙니다. 기존 `0.1.0-draft.1` 형식·검증기·예제를 보존하면서 다음을 추가했습니다.

- 크기와 데이터 제한이 있는 `.sjg` 가져오기·내보내기, 안정 ID와 알 수 없는 데이터 보존
- 지정 요소 조회·원자적 부분 수정, 오래된 revision 거절, 스냅샷 되돌리기
- 모듈 등록, 텍스트·이미지·선택 모듈, 미지원 기능의 비활성 대체 표시
- 랜딩·가로 스크롤·선택형 장면의 웹 재생과 작은 편집 실험실
- 로컬 저장·조회 소유권과 HTTP 충돌 검사

실제 손잡고 비공개 `.sjg` 저장·미리보기, ChatGPT 파일 편집 확장 설치, Sites 호스팅, 손잡고 앱·Remotion·FilmCraft 실행은 아직 검증하지 못했습니다. 기존 손잡고 발행 도구에 `.sjg` 수신 기능이 없으므로 어댑터는 미지원·변환 필요를 반환하고 발행하지 않습니다.

## 로컬 실행

Node.js 22.12.0 이상과 npm이 필요합니다. 계정·API 키·외부 서비스는 필요 없습니다.

```sh
npm ci --ignore-scripts
npm run check
npm run demo
```

`http://127.0.0.1:4173`에서 예제를 선택해 특정 블록을 수정하고 `.sjg`로 내보내거나 다시 가져올 수 있습니다. 편집 내용은 메모리에만 있으며, 내보내기 전 새로고침하면 사라집니다.

`check`는 기존 검사와 새 동작 검사, 타입 검사, 라이브러리·브라우저 빌드, 예제 6개 검증을 실행합니다. 기존 `npm run validate -- 작품.sjg`는 구조만 검증하며 재생·권한 검증을 대신하지 않습니다.

원래 예제는 `examples/`, 새 재생 예제는 `examples/runtime/`에 분리했습니다. [모듈 개발 안내](docs/modules.md)와 [파일 실행 제한](docs/sjg-format.md)을 확인해 주세요. 현재 코어는 지원하지 않는 값을 조용히 변환하지 않고 거절합니다. 원본 파일은 보존해야 합니다.

공개 코드에는 합성 예제만 포함합니다. 개인 작품·인증 정보·운영 데이터는 포함하지 않습니다. 기존 [Apache-2.0 라이선스](LICENSE)와 Git 이력을 유지합니다.
