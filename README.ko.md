# SonTool v3.0

**사람과 AI가 함께 만들고 발전시키는, 이동 가능한 작품의 공개 창작 엔진.**

[English](README.md) · [구조와 방향](docs/architecture.md) · [첫 기초공사 지시서](docs/foundation-engineering.md)

SonTool은 기존 **SonETool과 별개의 새 공개 프로젝트**입니다. 이야기·페이지·인터랙티브 경험·멀티미디어 작품을 하나의 창작 기반에서 다루는 것을 목표로 합니다.

- **SonTool GPT:** ChatGPT에 맞춘 전용 창작 환경.
- **SonTool App:** 여러 AI와 손잡고 앱이 연결되는 창작 환경.
- **공통 `.sjg` 작품:** 특정 AI나 화면에 종속되지 않고 두 환경 사이를 이동하는 작품.

## 지금 만들어진 것

현재는 **저장소 초기 토대**입니다. SonTool v3.0 제품 전체나 편집기가 완성된 상태는 아닙니다.

실제로 실행할 수 있는 것은 실험용 JSON 작품의 구조 검증, 전체 작품 안의 ID 중복 검사, 파일 읽기·쓰기 왕복, 세 가지 합성 예제 검증입니다. 동작 검증 테스트와 다음 개발을 위한 기준 문서를 함께 제공합니다.

공동 편집, 부분 수정, 리비전 충돌 거절, 되돌리기, 재생기, GPT/App 화면, Skill·Template 조회, 손잡고 비공개 미리보기와 승인 발행, Remotion·FilmCraft 연동은 **후속 구현 범위**입니다.

예제의 랜딩·스크롤·선택형 구조는 데이터 표현 후보입니다. 화면 재생·분기 동작·실제 서비스 호환성을 검증한 결과로 해석하면 안 됩니다. `.sjg`의 내부 형식도 아직 안정 규격이 아닙니다.

## 직접 실행

Node.js **22.12.0 이상**과 npm이 필요합니다. AI 계정·API 키·서버·DB는 필요하지 않습니다.

```sh
git clone https://github.com/paradigmdragon/sontool.git
cd sontool
npm ci --ignore-scripts
npm run check
```

내 컴퓨터에 있는 작품 초안은 다음처럼 검사합니다.

```sh
npm run validate -- /path/to/work.sjg
```

파일은 로컬에서 읽으며 업로드하지 않습니다. 실패하면 명령의 종료 상태로 알려 줍니다. `npm run check`는 테스트와 공개 예제 세 개를 검사합니다. 아직 앱 빌드 단계는 없습니다.

## 개발 방향

**작품 → 페이지 → 장면 → 블록**을 기본 후보로 삼고 내용·배치·시간·행동·상태를 나누어 다룹니다. 작품의 정체성과 원문을 보존하면서 사람과 AI가 필요한 부분을 수정하고, 다양한 재생기와 창작 도구가 연결되는 구조를 검증합니다.

다음 작업자는 [AGENTS.md](AGENTS.md)와 [첫 기초공사 지시서](docs/foundation-engineering.md)를 먼저 읽으세요. 기존 자산은 실제 위치·기능·라이선스·공개 가능 범위를 확인한 뒤 재사용합니다. 비공개 손잡고·SonETool 코드를 이 저장소에 옮기는 승인은 포함하지 않습니다.

공개 코드와 개인 작품·인증 정보·운영 데이터는 분리합니다. 저장소 예제는 전부 합성 데이터입니다. `.gitignore`만으로 비밀 보호가 보장되지는 않으므로 게시할 파일 목록을 직접 검토합니다.
